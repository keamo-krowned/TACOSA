# TACOSA

This GitHub repository contains the **CMPG223 project for TACOSA**.

TACOSA is a system that allows users to **search for, explore, and book accommodation and attractions in one place**. The aim is to provide users with a simple and convenient platform where they can manage different aspects of their travel arrangements without having to use multiple services.

This repository contains the everything for the development for TACOSA as part of the CMPG223 project.
